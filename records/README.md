# Public verification records

This directory is empty until a real `101Ts3t` purchase receives a finalized
`PASS` from dothat.quest.

Each future record directory will contain the exact public proof package, the
small public predicate used by GitHub Actions, and the Sigstore verification
bundle. Raw traces, participant identifiers, payment details, credentials and
submission capabilities are never stored here.

The GitHub/Sigstore attestation establishes which public workflow anchored the
exact package bytes and when. It does not replace the signed provider and review
artifacts inside the package.
